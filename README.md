# TinyInvoice

Free live invoice preview in the browser — no signup.

<h2 align="center"><a href="https://summerlv.github.io/Tinystep/">Try it →</a></h2>

<p align="center"><a href="https://summerlv.github.io/Tinystep/">https://summerlv.github.io/Tinystep/</a></p>

**Trying it** means filling the form and watching the live preview update. No signup. **Fill sample invoice** loads a freelance example in one click; edits after that still update the preview. On a phone, that button stays on screen, and a live total stays with the form while you edit. The header **EN | 中文** control switches the page chrome. Text you type into the invoice stays as entered, and the choice is saved in this browser.

PDF unlock is optional. The $1 button uses a Stripe **TEST** Payment Link — not a real payment ask.

Feedback: [Issue #2](https://github.com/SummerLv/Tinystep/issues/2)

The page keeps **Copy link** and adds a **Leave feedback** button to that issue. After you edit From, Bill to, or a line item, a one-time note (saved in this browser) asks for a one-line comment. Dismiss it with Not now. No signup.
